# 一起出发前 · 旅行偏好互检表

当前源码位于 [`../../docs/travel/`](../../docs/travel/)，入口为 `index.html`。从原项目的 `dist/` 迁入后，按用户要求删除了「题目来源」入口、弹窗、网页与导出图中的来源文字，以及发布目录中的九张原图。当前发布目录保留五个文件，题干、示例、答题、筛选与保存逻辑沿用原版。

在仓库根目录运行 `python scripts/serve.py`，打开 <http://127.0.0.1:8736/mini-tests/travel/>。详细使用与发布方法见[仓库说明](../../README.md)。

## 内容与使用

- 四类：吃得开心 6 题、空间共享 12 题、体验感 6 题、出门玩 12 题。
- 每题 YES / NO，可修改或清除；称呼选填，可按类别和未答状态筛选。
- 不计分、不判断性格或匹配度，供旅伴逐题人工对照。
- Canvas 导出包含全部 36 题和四类配色；未选择的题目标为「未答」。
- 使用 localStorage 键 `before-we-go-preferences-v1`，浏览器本地保存，不上传或自动跨域同步。
